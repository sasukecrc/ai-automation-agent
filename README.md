# AI Automation Agent

An autonomous AI-powered automation agent that finds high-paying remote jobs, builds real software projects, and manages your entire job hunt 24/7.

## What It Does

- **Job Search** — Scans 10+ sources for remote software jobs ($100k-$220k)
- **Auto-Apply** — Generates tailored cover letters and submits applications
- **Project Building** — Creates real GitHub projects to demonstrate skills
- **24/7 Operation** — Runs on cloud servers, works while you sleep
- **Tracker** — Maintains Google Sheets with job status, salary, and follow-ups

## Tech Stack

- OpenCode AI — Agentic coding
- Composio — 500+ app integrations (Gmail, Sheets, LinkedIn, GitHub, Canva, YouTube)
- MCP Servers — Puppeteer, Filesystem, GitHub, JobGPT, Context7
- Google Workspace — Docs, Sheets, Drive, Gmail
- GitHub — Code hosting and version control

## Connected Apps

## Quick Start

```bash
# Install opencode
curl -fsSL https://opencode.ai/install | bash

# Set API keys
export JOBGPT_API_KEY="your_key_here"

# Run opencode
opencode
```
